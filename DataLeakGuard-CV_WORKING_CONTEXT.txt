Documented architecture (verified against current source on 2026-11-02)
- Backend: FastAPI, SQLAlchemy, SQLite, under backend/app.
- Frontend: React/TypeScript/Vite, under src.
- API client: src/services/api.ts.
- Core persisted domain: datasets, leakage findings/evidence, repair/quarantine
  records, authentication/session, and owner-scoped workflow records.
- Five detectors: exact duplicates, entity overlap, target leakage, temporal
  leakage, train/test contamination.
- Uploaded originals and generated outputs use backend/storage subdirectories.
- Analysis accepts configured target/entity/split/time columns.
- `backend/app/main.py` registers datasets, findings, workspace and workflow
  routers. Data endpoints depend on `get_current_user`; dataset and finding
  queries are scoped through `Dataset.owner_user_id == user.id`.
- `GET /api/v1/datasets/{id}/findings` currently returns an unbounded array.
  The workspace router also defines the same path; datasets router is
  registered first. `src/services/api.ts:getFindings` expects an array.
  `LeakageAnalysisPage` loads all persisted findings and filters in-browser.
- `AnalysisPage` has four native selects and shows current-run findings
  separately; it has no recommendation endpoint or explicit confirmation state.
- Dataset upload persists `columns` with dtype, missing count, unique count,
  numeric summary or top 10 categorical values, plus six preview rows.
  Recommendations can use bounded stored metadata without rereading files.
- `DatasetDetailPage` displays all profile columns without controls, loads all
  findings on its tab, and shows dataset history as basic type/outcome/time
  cards.
- Existing `GET /datasets/{id}/history` is owner-scoped, merges audit events
  and repair records in Python, loads all matching operations before truncating,
  and has no type/status/date/search filters or pagination.
- Backend `conftest.py` creates per-test SQLite DBs, redirects storage
  constants to per-test `tmp_path`, and overrides auth. Full baseline was run
  from a disposable backend source copy with no project DB/storage copied.
